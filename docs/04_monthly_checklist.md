# 月次試算表 チェックリスト

毎月、前月末の試算表を銀行へ出すまでの作業手順です。
チェックを付けながら使う版（月ごとに記録が残る）は claude.ai のアーティファクト「試算表 月次チェックリスト」にあります。
項目を変えたときは、このファイルとアーティファクトの両方を直してください。

提出の目安：**翌月10日**（例：9月末の試算表は10月10日まで）

## 1. 月初〜4日：freee の帳簿を整える

- [ ] 銀行・カードの明細が同期されているか確認する（南都、ゆうちょ（法人）、楽天（法人）、楽天ビジネスカード、アメックス、デルタカード。止まっていれば再連携）
- [ ] 「自動で経理」の未処理明細をゼロにする
- [ ] 手元の現金を数え、freee の現金残高と合わせる
- [ ] 売上をすべて計上する（小売、卸の請求書、EC、海外。月末締めの請求書は月末日付で売掛金）
- [ ] 売掛金と代引き（e-コレクト）の入金を消し込む。売掛金が増えていればどの取引先か確認
- [ ] 仕入・外注加工費の請求書を計上する（製茶・ティーバッグ・袋詰・コーヒー、袋・豆などの材料。月内に届いた分は未払金）
- [ ] 給与・役員報酬・社会保険料を計上する（法定福利費が毎月入っているか）
- [ ] 毎月の固定費が入っているか確認する（地代家賃、茶畑地代、リース料、保険料、通信費、水道光熱費）
- [ ] 借入金の返済を元金（長期借入金）と利息（支払利息）に分けて計上する
- [ ] カードと役員立替の精算を確認する（負債の科目がマイナス残高になっていないか）
- [ ] 仮払金・仮受金・立替金の残りを確認し、正しい科目に振り替える

## 2. 5日：試算表アプリに取り込む

- [ ] 前月分の自動取込（毎月5日 6:00）が届き、取込画面で「完了」になっているか確認する
- [ ] 5日以降に freee を直したら、取込画面から取り込み直す

## 3. 5〜8日：棚卸補正と数字の確認

- [ ] 月末棚卸の見積方法を決める（通常は据置法。在庫が大きく動いた月は実地簡易棚卸で荒茶 kg × 単価を入力）
- [ ] 減価償却の月割を入れるか決める（銀行に求められた場合のみ。入れたら毎月そろえる）
- [ ] 検算がすべて ✓ になっているか確認する
- [ ] 前期同期と大きく違う科目に説明を用意する
- [ ] 月次推移で、その月だけ極端な数字がないか確認する（計上月のずれ、二重計上）

## 4. 8〜10日：添える資料を整える

- [ ] 当期の施策の進捗を更新する
- [ ] 借入金明細（借入先ごとの残高・月返済額）を更新する
- [ ] 事業計画書など添付資料が最新か確認する

## 5. 10日まで：確定して提出する

- [ ] 「この内容で確定」を押して版を保存する
- [ ] 提出用ページを開き、ブラウザの印刷から PDF に保存する
- [ ] PDF と添付資料を銀行へ送る（または持参）
- [ ] 提出履歴に提出先と提出日を記録する

## 年に一度

**2月末（決算月）**
- [ ] 実地棚卸をする（製品・仕掛品（荒茶）・原材料）。翌期の据置法の基準になる
- [ ] 実地簡易棚卸で使う単価（荒茶 kg 単価・製品原価）を見直す

**決算が確定したら（通常5月）**
- [ ] 取込画面で「前期以前の決算データも取り直す」に印を付けて取り込む
- [ ] 前期の決算書とアプリの数字（売上高・当期純利益・純資産・棚卸資産）が一致しているか確認する
